# External Verification

This directory indexes stable third-party verification records for Xitcoin. Smart-contract audit evidence remains in [`audits/`](../audits/).

## Cyberscope project profile

- Profile: [XITCOIN on Cyberscope](https://www.cyberscope.io/audits/1-xtc)
- Cronos contract displayed by Cyberscope: `0xE45FE733BC8617FA6DAC8437FC44B5FFFA949991`
- Audited source and exact SHA-256 scope: [`audits/cyberscope-v2.md`](../audits/cyberscope-v2.md)

The profile contains live scores, rankings and audience statistics maintained by Cyberscope. Those mutable values are not duplicated here.

## KYC record

Cyberscope reports a passed KYC assessment and publishes the certificate in its official GitHub repository:

- [Cyberscope KYC certificate for XITCOIN](https://github.com/cyberscope-io/kyc/blob/main/1-xtc/kyc.png)

KYC is an identity-verification record. It is separate from source-code review and does not change the audit scope recorded in [`audits/`](../audits/).

## Reference policy

A record is included here only when it has a stable URL controlled by the issuing organization. If a provider updates or withdraws a record, the provider's current publication is authoritative.
